# 双模式招聘流程演示

两套资料均为虚构数据。每套包含一份 UTF-8 文本简历和三轮面试全文，可直接在页面上传。简历和面试文字需要选择对应的候选人及轮次。

## 模型设置

在页面右上角的“模型设置”中，规则模式选择“规则演示”；模型模式选择“自定义模型”，填写服务商提供的 OpenAI 兼容接口地址、模型名称和 API Key（无鉴权时可留空）。点击“测试模型连接”确认服务能生成文本。非 OpenAI 兼容协议需要额外适配。

## 页面操作

1. 进入“AI 招聘助手”，上传对应的 `简历_姓名.txt` 并发送。在“简历评估”中核对信息，选择“进入一面”并确认。
2. 进入“候选人管理”，在对应申请行点击“安排面试”。按上表选择时间，一、二、三面的面试官分别为李工、王工、赵工。
3. 在“面试记录”中找到对应的待进行面试，点击“上传文字”，依次使用对应轮次的文件。核对总结和建议，选择“推进”并确认。也可以先选择“待定”，再通过申请行的“记录反馈”人工推进。
4. 三面推进后，依次点击“确认接受 Offer”和“确认入职”。每个决定均由人工作出。

规则演示只提取明确标注的信息、发言和主题，不生成 AI 评分；真实模型会提供 AI 参考总结、建议及有原文依据的评分。模型生成需要一定时间。

## 隔离流程测试

在项目根目录运行以下 PowerShell 命令。脚本会创建并清理临时数据库，不修改页面正在使用的招聘数据：

```powershell
.\backend\.venv\Scripts\python.exe scripts\simulate_recruitment.py
```

脚本默认只运行规则模式。测试模型时先在项目 `.env` 文件中设置 `MODEL_NAME`、`MODEL_BASE_URL` 和可选的 `MODEL_API_KEY`，再运行 `--mode model`；也可使用 `--mode both` 顺序测试两种模式，或用 `--model-config <文件路径>` 指定另一份配置文件。密钥不放在命令行参数中。
